## README

These examples map the official EmDash examples to native First and WordPress.
The canonical source is pinned at
[`1824902c0c383c052b623528799427b8a5ff75d0`](https://github.com/emdash-cms/emdash/tree/1824902c0c383c052b623528799427b8a5ff75d0).
The behavioral counterparts use WordPress collections, native editor/SCF, PHP
frontends and generated Abilities. [Official source migrations](https://github.com/spacefast/zero/blob/main/examples/emdash/official-sites/README.md)
also retain the original blank, starter and blog Astro frontends, backed by native
First data. Astro builds to Node; First backend TypeScript and selected original
helpers compile to PHP. Provider and editor contracts remain explicit.

**Native qualification is partial.** Publication, marketing, portfolio, plugins,
agent and platform acceptance runs have passed their recorded native checks,
with browser journeys for the publication, marketing, portfolio, plugin, agent
and platform surfaces. These results cover the executed subsets, not every behavior
in the official examples.
[manifest.json](https://github.com/spacefast/zero/blob/main/examples/emdash/manifest.json) records source object IDs, scoped execution
receipts, owners, commands, pending proofs and known gaps.
[The coverage guide](https://github.com/spacefast/zero/blob/main/docs/emdash-coverage.md) explains the differences.

Run from the repository root with Node.js 22.23.4+, npm/npx and the Rust toolchain.
Studio supplies WordPress, PHP and SQLite; Docker is not required:

```sh
node examples/emdash/test.mjs
```

The runner builds First with `cargo build --locked`, refreshes the shared browser
dependencies and Chromium, then runs `publishing`,
`publishing-browser`, `marketing`, `portfolio`, `agents`, `platform`, `plugins`
and `official-source`
sequentially. Set `FIRST_BIN` to an existing matching binary to skip the build.
Select suites by name; the native lifecycle suite is optional:

```sh
node examples/emdash/test.mjs official-source
node examples/emdash/test.mjs marketing portfolio
node examples/emdash/test.mjs lifecycle
```

Start a disposable example after building First:

```sh
node examples/emdash/blank/run.mjs
node examples/emdash/starter/run.mjs
node examples/emdash/blog/run.mjs
node examples/emdash/portfolio/dev.mjs
node examples/emdash/plugins/studio.mjs
```

To run an individual browser test directly, install the shared dependencies once:

```sh
npm --prefix examples/emdash ci
npm --prefix examples/emdash exec -- playwright install chromium
```

Each launcher prints its public/admin URLs and exact cleanup command. The
[marketing guide](https://github.com/spacefast/zero/blob/main/examples/emdash/marketing/README.md#explore-and-edit),
[agent notebook](https://github.com/spacefast/zero/blob/main/examples/emdash/agents/README.md) and [platform journal](https://github.com/spacefast/zero/blob/main/examples/emdash/platform/README.md)
describe their interactive setup. Edit the stored content in WordPress admin
and reload the public page to see the saved result. The intentionally tracked
`admin` / `first-test-admin` credentials belong only to these disposable local
sites; never reuse them for personal accounts or deployed sites. Application
passwords generated by a test are scoped to that test site.

Each run must own a unique disposable project, a free port, its `.first/dev`
receipt, database, uploads and Studio registration. Keep the printed evidence
and cleanup result. A failed run remains a failure until repaired and rerun;
retained sites require cleanup by their exact project receipt. Manually launched
sites stay running until their printed cleanup command is used. Never use a
global Studio stop/delete command.

A local pass proves only the behaviors actually exercised. Exact Cloudflare
D1/R2/Access/Images/Stream/cache, PostgreSQL, Worker isolation, AI Search/Llama
Guard, AT Protocol, x402 and hosted builder parity need their own implementations
and provider evidence. Ordinary WordPress drafts/revisions do not establish
EmDash's separate live/staged-draft semantics. An MCP echo is connectivity proof,
not an AI site-builder qualification.
