## README

Keep a private maintenance log for the systems in your house. Use WordPress
admin, Secure Custom Fields, and [First Admin](https://github.com/spacefast/zero/blob/main/docs/admin.md). There is no
custom frontend.

Each WordPress user owns their systems, recurring tasks, and work logs. Owner
filters apply to lists, edits, REST requests, and agent abilities. Hooks set
`ownerId` from the signed-in account and preserve it on updates. Even another
administrator cannot read your rows through the app.

```sh
cargo build --locked --bin zero
```

Create a home system first, then a task referencing that system. Enter rich

record completion and schedule the next visit. Open the resulting work log to
attach a photo using the standard media picker.

## Data and actions

| Resource | Fields |
| --- | --- |
| `systems` | Name, room, kind, make, model, installation date, private PDF manual |
| `tasks` | System, title, repeat interval in days, last completion, next due date, rich instructions, overdue stamp |
| `doneLogs` | Task, completion date, notes, integer cost in cents, photo, original system snapshot |

Kinds are `hvac`, `plumbing`, `electrical`, `appliance`, and `safety`.
All dates and scheduling use UTC. Keep costs in one currency for a given home.
Ordinary WordPress media URLs are public on an unrestricted host. Keep a hosted
Space restricted when you attach personal photos.

| Action | Input | Result |
| --- | --- | --- |
| `dueNext` | `days`, default 30 | Your tasks with `nextDueOn <= UTC today + days`, ordered by due date, including overdue tasks |
| `markDone` | `taskId`, optional `notes`, optional `costCents` | A work log and updated task, committed together |
| `yearCost` | `year` | Costs per system, including zero-cost systems, and the total |

`markDone` sets `lastDoneOn` to today, calculates `nextDueOn = today + everyDays`,
and clears `overdueAt`. Omitted cost is zero. Send an `Idempotency-Key` header
when retrying the same completion request. Reusing that key returns the same log.

`yearCost` sums `costCents` for logs owned by the caller with
`year-01-01 <= doneOn < (year + 1)-01-01`, grouped by the log's saved `systemId`.
Changing a task's system later does not move previous spending. Creating or
editing a work log directly records history; use `markDone` to advance a task.

### Overdue stamps

Creating a task, or changing its next due date, enqueues `flagOverdue` using the
stock `job()` API. Its delay is the number of seconds until UTC midnight after
the due day, with a minimum of zero. Action Scheduler delivers the job after
the task write commits. The job checks the current owner, due date, and stamp
before writing `overdueAt`. A queued job for an old due date does nothing after
you reschedule the task. There is no custom cron or recurring worker.

On a WordPress host, keep Action Scheduler running through its normal host
integration. To deliver currently due jobs locally:

```sh
./target/debug/first wp --site examples/home-maintenance action-scheduler run --hooks=first_job --force
```

### Private manuals

The `manuals` resource accepts PDF files up to 20,000,000 bytes. Its read and
delete rules are `owner`, meaning the uploader. Downloads use signed links
that expire after five minutes. The SCF field accepts a private file ID.
Upload through First's authenticated file endpoint, then paste that ID into
**Manual PDF**:

```sh
curl --fail-with-body --user "$FIRST_APP_PASSWORD" \
  -F 'file=@heat-pump-manual.pdf;type=application/pdf' \
  http://localhost:8896/wp-json/first/v1/files/manuals
```

The host must block direct access to `/wp-content/uploads/zero-private/`.
Studio currently fails that protection check and refuses uploads. See the
exact error below. Do not disable the protection check to make uploads work.

## Use it from your agent

Connect your agent's MCP client to:

```text
http://localhost:8896/wp-json/mcp/zero-home-maintenance
```

On your own WordPress installation, use the same path on its HTTPS origin.
Create an application password in **Users \> Profile \> Application Passwords**.
Configure HTTP Basic authentication with your WordPress username and that
application password. This is a WordPress credential, separate from Spacefast
visitor access. The required MCP Adapter plugin serves the abilities.

| Ask your agent | Ability |
| --- | --- |
| "What's due this month in the house?" | `home-maintenance/due-next`, with `days` equal to the days remaining in the month |
| "I cleaned the heat pump filters. Log 15.99 for supplies and schedule the next clean." | `home-maintenance/tasks-list` to find the task, then `home-maintenance/mark-done` with `costCents: 1599` |
| "How much did I spend on each system this year?" | `home-maintenance/year-cost` with the current year |

The adapter exposes these as MCP tools with slashes replaced by hyphens, such
as `home-maintenance-mark-done`. Collection tools include
`home-maintenance-systems-list`, `home-maintenance-tasks-list`, and
`home-maintenance-done-logs-list`, plus get, create, update, and delete variants.

For a direct action call, set `FIRST_APP_PASSWORD` in your shell to
`username:application-password`, then run:

```sh
curl --fail-with-body --user "$FIRST_APP_PASSWORD" \
  -H 'Content-Type: application/json' \
  --data '{"days":30}' \
  http://localhost:8896/wp-json/first/v1/actions/dueNext
```

## Customize it

Change `kind` options for your home, adjust the default `everyDays`, or add
fields such as filter size and warranty end date to `systems`. Use `.ui()` to
label the fields and add help in SCF. Extend `flagOverdue` if you need a
notification, keeping delivery inside the stock job API. Rebuild after each
schema change and review the generated migrations before applying them.

## `first.config.ts`

```ts title="first.config.ts"
import {
  action, collection, date, db, defineConfig, defineRelations, file, files,
  HttpError, integer, job, jobs, media, richText, text, timestamp,
  type InferSelectModel,
} from "first";
import { addDays, overdueDelay, today } from "./lib/dates";

const owner = integer().notNull().access({ create: false, update: false })
  .ui({ label: "Owner", help: "Set automatically from your WordPress account." });

export const systems = collection({
  name: text().notNull().min(1).max(120),
  ownerId: owner,
  room: text().notNull().min(1).max(80),
  kind: text({ enum: ["hvac", "plumbing", "electrical", "appliance", "safety"] }).notNull(),
  make: text().max(120),
  model: text().max(120),
  installedOn: date(),
  manual: file({ bucket: "manuals" }).ui({
    label: "Manual PDF", help: "Upload to /wp-json/first/v1/files/manuals, then enter its file ID.",
  }),
}, { title: "name", label: "Home systems", access: {
  read: (ctx) => ({ ownerId: ctx.user?.id ?? -1 }), create: "authenticated",
  update: (ctx) => ({ ownerId: ctx.user?.id ?? -1 }), delete: (ctx) => ({ ownerId: ctx.user?.id ?? -1 }),
} });

export const tasks = collection({
  title: text().notNull().min(1).max(160),
  ownerId: owner,
  systemId: integer().notNull().references(() => systems.id, { onDelete: "restrict" }),
  everyDays: integer().notNull().min(1).max(36500).default(90)
    .ui({ label: "Repeat every days", help: "The next date is calculated in UTC when you mark this task done." }),
  lastDoneOn: date(),
  nextDueOn: date().notNull().defaultNow(),
  instructions: richText(),
  overdueAt: timestamp().access({ create: false, update: false })
    .ui({ label: "Overdue since", help: "Stamped by Action Scheduler after the due day ends in UTC." }),
}, { title: "title", content: "instructions", label: "Maintenance tasks", access: {
  read: (ctx) => ({ ownerId: ctx.user?.id ?? -1 }), create: "authenticated",
  update: (ctx) => ({ ownerId: ctx.user?.id ?? -1 }), delete: (ctx) => ({ ownerId: ctx.user?.id ?? -1 }),
} });

export const doneLogs = collection({
  title: text().notNull().default("Maintenance completed"),
  ownerId: owner,
  taskId: integer().notNull().references(() => tasks.id, { onDelete: "restrict" }),
  systemId: integer().notNull().references(() => systems.id, { onDelete: "restrict" })
    .access({ create: false, update: false })
    .ui({ help: "The system maintained when this work was logged, preserved for yearly costs." }),
  doneOn: date().notNull().defaultNow(),
  notes: text({ multiline: true }).max(10000),
  costCents: integer().notNull().min(0).max(100000000).default(0),
  photo: media({ accept: "image" }),
}, { title: "title", label: "Work done", access: {
  read: (ctx) => ({ ownerId: ctx.user?.id ?? -1 }), create: "authenticated",
  update: (ctx) => ({ ownerId: ctx.user?.id ?? -1 }), delete: (ctx) => ({ ownerId: ctx.user?.id ?? -1 }),
} });

const collections = { systems, tasks, doneLogs };
const relations = defineRelations(collections, (r) => ({
  systems: { tasks: r.many.tasks() },
  tasks: {
    system: r.one.systems({ from: r.tasks.systemId, to: r.systems.id }),
    doneLogs: r.many.doneLogs(),
  },
  doneLogs: { task: r.one.tasks({ from: r.doneLogs.taskId, to: r.tasks.id }) },
}));

async function requireSystem(systemId: number, userId: number) {
  const system = await db.query.systems.findFirst({ where: { id: systemId, ownerId: userId } });
  if (!system) throw new HttpError(404, "not_found", "Home system not found");
  return system;
}

async function requireTask(taskId: number, userId: number) {
  const task = await db.query.tasks.findFirst({ where: { id: taskId, ownerId: userId } });
  if (!task) throw new HttpError(404, "not_found", "Maintenance task not found");
  return task;
}

async function scheduleOverdue(task: InferSelectModel<typeof tasks>) {
  await jobs.flagOverdue.enqueue({ taskId: task.id, ownerId: task.ownerId, dueOn: task.nextDueOn }, {
    delay: overdueDelay(task.nextDueOn), key: `overdue-${task.id}-${task.nextDueOn}`,
  });
}

export default defineConfig({
  name: "home-maintenance",
  admin: true,
  collections,
  relations,
  files: {
    manuals: files("manuals", {
      accept: ["application/pdf"], maxBytes: 20_000_000,
      access: { read: "owner", delete: "owner" },
    }),
  },
  hooks: {
    systems: {
      beforeCreate(data, ctx) {
        if (!ctx.user) throw new HttpError(401, "unauthenticated", "Sign in to maintain your home");
        data.ownerId = ctx.user.id;
        data.name = data.name.trim();
        data.room = data.room.trim();
      },
      beforeUpdate(patch, existing) {
        patch.ownerId = existing.ownerId;
        if (patch.name !== undefined) patch.name = patch.name.trim();
        if (patch.room !== undefined) patch.room = patch.room.trim();
      },
    },
    tasks: {
      async beforeCreate(data, ctx) {
        if (!ctx.user) throw new HttpError(401, "unauthenticated", "Sign in to maintain your home");
        data.ownerId = ctx.user.id;
        await requireSystem(data.systemId, data.ownerId);
        data.title = data.title.trim();
        data.overdueAt = null;
      },
      async beforeUpdate(patch, existing) {
        patch.ownerId = existing.ownerId;
        if (patch.systemId !== undefined) await requireSystem(patch.systemId, existing.ownerId);
        if (patch.title !== undefined) patch.title = patch.title.trim();
        if (patch.nextDueOn !== undefined && patch.nextDueOn !== existing.nextDueOn) patch.overdueAt = null;
      },
      afterCreate: scheduleOverdue,
      async afterUpdate(row, previous) {
        if (row.nextDueOn !== previous.nextDueOn) await scheduleOverdue(row);
      },
    },
    doneLogs: {
      async beforeCreate(data, ctx) {
        if (!ctx.user) throw new HttpError(401, "unauthenticated", "Sign in to maintain your home");
        data.ownerId = ctx.user.id;
        const task = await requireTask(data.taskId, data.ownerId);
        data.systemId = task.systemId;
        data.title = task.title + " on " + data.doneOn;
      },
      async beforeUpdate(patch, existing) {
        patch.ownerId = existing.ownerId;
        if (patch.taskId !== undefined && patch.taskId !== existing.taskId) {
          throw new HttpError(422, "invalid_input", "A work log stays with its original task");
        }
        patch.systemId = existing.systemId;
        const task = await requireTask(patch.taskId ?? existing.taskId, existing.ownerId);
        patch.title = task.title + " on " + (patch.doneOn ?? existing.doneOn);
      },
    },
  },
  actions: {
    dueNext: action({
      input: { days: integer().notNull().min(0).max(366).default(30) },
      access: "authenticated",
      async handler({ days }, ctx) {
        if (!ctx.user) throw new HttpError(401, "unauthenticated", "Sign in to maintain your home");
        const userId = ctx.user.id;
        const through = addDays(today(), days);
        const due = await db.query.tasks.findMany({
          where: { ownerId: userId, nextDueOn: { lte: through } },
          orderBy: { nextDueOn: "asc" },
        });
        return { through, tasks: due };
      },
    }),
    markDone: action({
      input: {
        taskId: integer().notNull(), notes: text().max(10000),
        costCents: integer().min(0).max(100000000),
      },
      access: "authenticated",
      idempotent: true,
      async handler({ taskId, notes, costCents }, ctx) {
        if (!ctx.user) throw new HttpError(401, "unauthenticated", "Sign in to maintain your home");
        const userId = ctx.user.id;
        const task = await requireTask(taskId, userId);
        const doneOn = today();
        const [log] = await db.insert(doneLogs).values({
          taskId, ownerId: userId, systemId: task.systemId,
          doneOn, notes: notes ?? "", costCents: costCents ?? 0,
        }).returning();
        const [updated] = await db.update(tasks).set({
          lastDoneOn: doneOn, nextDueOn: addDays(doneOn, task.everyDays), overdueAt: null,
        }).where({ id: taskId, ownerId: userId }).returning();
        return { log, task: updated };
      },
    }),
    yearCost: action({
      input: { year: integer().notNull().min(1900).max(9998) },
      access: "authenticated",
      async handler({ year }, ctx) {
        if (!ctx.user) throw new HttpError(401, "unauthenticated", "Sign in to maintain your home");
        const userId = ctx.user.id;
        const homeSystems = await db.query.systems.findMany({ where: { ownerId: userId }, orderBy: { name: "asc" } });
        const logs = await db.query.doneLogs.findMany({
          where: { ownerId: userId, doneOn: { gte: `${year}-01-01`, lt: `${year + 1}-01-01` } },
        });
        const spend = homeSystems.map((system) => {
          const costs = logs.filter((log) => log.systemId === system.id);
          return { systemId: system.id, name: system.name, costCents: costs.reduce((sum, log) => sum + log.costCents, 0) };
        });
        return { year, systems: spend, totalCents: spend.reduce((sum, system) => sum + system.costCents, 0) };
      },
    }),
  },
  jobs: {
    flagOverdue: job({
      input: { taskId: integer().notNull(), ownerId: integer().notNull(), dueOn: date().notNull() },
      retries: 3,
      async handler({ taskId, ownerId: userId, dueOn }) {
        const task = await db.query.tasks.findFirst({ where: { id: taskId, ownerId: userId } });
        if (!task) return;
        if (task.nextDueOn !== dueOn || task.nextDueOn >= today() || task.overdueAt !== null) return;
        await db.update(tasks).set({ overdueAt: new Date().toISOString() })
          .where({ id: taskId, ownerId: userId, nextDueOn: dueOn, overdueAt: { isNull: true } });
      },
    }),
  },
});
```
