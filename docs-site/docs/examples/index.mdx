Each example below is a directory in [`examples/`](https://github.com/spacefast/zero/tree/main/examples). Its page shows the files you write and every file `first build` writes for them, built when this site was built.

| Example | What it shows |
| --- | --- |
| [Reading list](/examples/reading-list) | A reading log in 94 lines. Books are WordPress posts, reads are a SQL table, and each reader sees only their own. |
| [Pantry](/examples/pantry) | A pantry tracker. Three SQL tables, a hook that writes the shopping list, two actions and a background job. |
| [Blog](/examples/blog) | A publication. Posts in two languages, authors, moderated comments, member accounts, image sizes, private files and signed webhooks. |
| [Full site](/examples/full-site) | A small editorial site. Pages written in TSX, rendered by WordPress, with one button that runs on the Interactivity API. |

The repository has more examples. Some are tests, some are unfinished.
