## README

A personal pet pantry whose interface is WordPress. Pets and foods have native
wp-admin edit screens with generated Secure Custom Fields groups. Vet notes use
Gutenberg. `admin: true` includes First Admin for the SQL tables. There are no
custom frontend components, public assets, pages, or frontend dependencies.

**The app is not running yet.** Main rejects the exported `AccessCtx` type.
The Spacefast CLI published a restricted static source listing instead of a
First app. Local actions, admin screenshots, and live app verification are not
done. The exact blockers are recorded below.

## Storage choices

| Entity | Storage | Why |
| --- | --- | --- |
| `pets` | `collection()` | Named profiles with media photos, native edit screens, and revisions. `name` is the post title. |
| `foods` | `collection()` | A product catalog edited through SCF, with pack photos and revisions. `product` is the post title. |
| `vetNotes` | `collection()` | Editorial content. `title` maps to the post title and `body: richText()` maps to Gutenberg content. Each note references a pet. |
| `stock` | `table()` | Pack balances and opening/expiry dates are operational records without publishing or revisions. Each pack references a food. |
| `feedings` | `table()` | An append-only ledger written by `feed`, including a meal price snapshot. Generic create, update, and delete are denied. |
| `shoppingList` | `table()` | One candidate per food. Action Scheduler marks candidates that need restocking. Clients cannot mutate the background job's results. |

Every row has an `ownerId` assigned by `beforeCreate` from the signed-in
WordPress user, overwriting client input. Read, update, and delete rules return
an owner filter. Reference hooks reject another user's pets and foods. Internal
action database calls are trusted by First, so actions explicitly filter by
owner too. Guests cannot use this app.

`foods.afterCreate` creates the shopping-list candidate while the user's actor
is available. Scheduler jobs have no signed-in user. The authenticated enqueue
path supplies the food and owner IDs. The job checks that pair and updates the
existing candidate, preserving its owner. The internal job has `agents: false`.

## Actions and formulas

| Action | Input | Behavior |
| --- | --- | --- |
| `feed` | `petId`, `foodId`, `grams`, optional `fedAt` | Checks ownership, rejects future times and insufficient unexpired stock, subtracts across packs, opens a pack when first used, and logs one feeding. Use a fresh `Idempotency-Key` per meal and reuse it when retrying that meal. |
| `runsOutOn` | `foodId` | Returns usable grams, recent daily consumption, days remaining, a projected UTC date, and whether restocking is needed. |
| `costPerMonth` | `petId` | Returns a monthly estimate in cents using prices captured when feeding. |
| `restockList` | `{}` | Returns foods with no usable stock or at most a week remaining and queues shopping-list checks. |

History uses `now - 14 days <= fedAt <= now`, filtered by owner and the selected
food or pet. All prices must use one currency.

| Value | Formula and filters |
| --- | --- |
| Usable grams | Sum positive `stock.gramsLeft` for the owner and food, with no expiry or `expiresOn >= today`, using UTC dates. |
| Grams per day | Sum grams served for the food in the history window, divided by 14. The pet's `dailyGrams` is a target, not measured history. |
| Runs out on | `now + usable grams / grams per day`, converted from days to milliseconds, then formatted as a UTC date. Positive stock without consumption history returns null. Empty usable stock returns today. |
| Meal cost | `grams * food.costCents / food.bagGrams`, saved as fractional cents. |
| Monthly cost | `round(sum of the pet's meal costs in the history window / 14 * 30)`. |
| Restock | Usable grams equal zero, or measured days remaining are at most 7. |

Short histories still use the full window. Estimates can be low during setup.
Backdated feedings consume today's stock. Forecasts exclude packs already
expired but do not predict future waste. Pack selection orders by expiry then
ID; null expiry follows the database's null ordering.

The scheduler refreshes stored candidates after food creation, stock changes, and after
`feed` or `restockList`. It has no daily sweep. If only time passes, run
`restockList` to refresh expiry and history-window changes. The table includes
all candidates; filter `needed: true` to read the current shopping list:

```sh
curl --get --fail-with-body -u "$FIRST_AUTH" \
	--data-urlencode 'where={"needed":true}' \
	'http://localhost:8897/wp-json/first/v1/shopping_list'
```

## Customize the admin

Edit [lib/schema.ts](https://github.com/spacefast/zero/blob/main/examples/pet-food/lib/schema.ts), then rebuild:

| Change | Mechanism |
| --- | --- |
| Field groups | Add fields to a post-backed `collection()`. First regenerates its SCF group. `.ui({ label, help, placeholder, width })` configures supported SCF controls. Edit the schema rather than its generated local SCF group. |
| Labels | Change a resource's `label` for menus and screens. Use field `.ui()` labels independently of API names. |
| Title and Gutenberg | `title` chooses the native post title. `content` chooses the rich-text field rendered in Gutenberg. Pets and Foods use SCF forms without a block-editor body. |
| List columns | First Admin derives fields from the schema and lets you choose visible columns in its table view. Classic wp-admin uses native title/date columns. Main has no per-resource option for custom classic list columns or their order. |
| Menus | Register collections for native wp-admin menus and tables for First Admin. Access rules determine the data users can reach. Main has no separate menu-visibility option. |
| Icons | Main hardcodes `dashicons-database` for generated post types. There is no supported per-resource icon option. |

`ownerId` cannot be updated through clients. Hiding a menu never changes access
rules. Keep reference ownership checks when adding relations. Review generated
SQL before applying field removals or type changes to existing personal data.

## `first.config.ts`

```ts title="first.config.ts"
import { action, db, defineConfig, HttpError, integer, job, real, timestamp } from "first";
import { collections, tables, relations, feedings, stock, shoppingList } from "./lib/schema";
import { DAY_MS, WINDOW_DAYS, ownerId, ownFood, ownPet, projection, queueStockCheck, usableStock } from "./lib/pantry";

export default defineConfig({
  name: "pet-food",
  admin: true,
  collections,
  tables,
  relations,
  hooks: {
    pets: {
      beforeCreate(data, ctx) { data.ownerId = ownerId(ctx); data.name = data.name.trim(); },
      beforeUpdate(patch, existing) { patch.ownerId = existing.ownerId; },
    },
    foods: {
      beforeCreate(data, ctx) { data.ownerId = ownerId(ctx); data.product = data.product.trim(); },
      beforeUpdate(patch, existing) { patch.ownerId = existing.ownerId; },
      async afterCreate(row) {
        // Create the owned candidate while the signed-in user's actor is available.
        await db.insert(shoppingList).values({ foodId: row.id, ownerId: row.ownerId });
        await queueStockCheck(row.id, row.ownerId);
      },
    },
    vetNotes: {
      async beforeCreate(data, ctx) {
        data.ownerId = ownerId(ctx);
        await ownPet(data.petId, data.ownerId);
      },
      async beforeUpdate(patch, existing) {
        patch.ownerId = existing.ownerId;
        await ownPet(patch.petId ?? existing.petId, existing.ownerId);
      },
    },
    stock: {
      async beforeCreate(data, ctx) {
        data.ownerId = ownerId(ctx);
        await ownFood(data.foodId, data.ownerId);
      },
      async beforeUpdate(patch, existing) {
        patch.ownerId = existing.ownerId;
        await ownFood(patch.foodId ?? existing.foodId, existing.ownerId);
      },
      async afterCreate(row) { await queueStockCheck(row.foodId, row.ownerId); },
      async afterUpdate(row, previous) {
        await queueStockCheck(row.foodId, row.ownerId);
        if (previous.foodId !== row.foodId) await queueStockCheck(previous.foodId, previous.ownerId);
      },
      async afterDelete(row) { await queueStockCheck(row.foodId, row.ownerId); },
    },
    feedings: {
      async beforeCreate(data, ctx) {
        data.ownerId = ownerId(ctx);
        await ownPet(data.petId, data.ownerId);
        await ownFood(data.foodId, data.ownerId);
      },
    },
    shoppingList: {
      async beforeCreate(data, ctx) {
        data.ownerId = ownerId(ctx);
        await ownFood(data.foodId, data.ownerId);
      },
      beforeUpdate(patch, existing) { patch.ownerId = existing.ownerId; },
    },
  },
  jobs: {
    checkLowStock: job({
      input: { foodId: integer().notNull(), ownerId: integer().notNull() },
      agents: false,
      retries: 3,
      async handler(input) {
        const food = await db.query.foods.findFirst({ where: { id: input.foodId, ownerId: input.ownerId } });
        if (!food) return;
        const forecast = await projection(food.id, food.ownerId);
        // Scheduler jobs have no user. Update the user's pre-created candidate.
        await db.update(shoppingList).set({ needed: forecast.needsRestock, checkedAt: new Date().toISOString() })
          .where({ foodId: food.id, ownerId: food.ownerId });
      },
    }),
  },
  actions: {
    feed: action({
      access: "subscriber",
      idempotent: true,
      input: {
        petId: integer().notNull(), foodId: integer().notNull(),
        grams: real().notNull().min(0.01), fedAt: timestamp(),
      },
      async handler(input, ctx) {
        const owner = ownerId(ctx);
        await ownPet(input.petId, owner);
        const food = await ownFood(input.foodId, owner);
        const now = Date.now();
        const fedAt = input.fedAt ?? new Date(now).toISOString();
        if (new Date(fedAt).getTime() > now) {
          throw new HttpError(422, "invalid_input", "A feeding cannot be in the future.");
        }
        const today = new Date(now).toISOString().slice(0, 10);
        const lots = await usableStock(input.foodId, owner, today);
        const available = lots.reduce((sum, lot) => sum + lot.gramsLeft, 0);
        if (available < input.grams) throw new HttpError(409, "insufficient_stock", "Not enough unexpired food.");
        let remaining = input.grams;
        for (const lot of lots) {
          if (remaining <= 0) break;
          const served = Math.min(remaining, lot.gramsLeft);
          const [updated] = await db.update(stock).set({
            gramsLeft: lot.gramsLeft - served, openedOn: lot.openedOn ?? today,
          }).where({ id: lot.id, ownerId: owner, gramsLeft: lot.gramsLeft }).returning();
          if (!updated) throw new HttpError(409, "stock_changed", "Stock changed. Retry the feeding.");
          remaining -= served;
        }
        const [feeding] = await db.insert(feedings).values({
          petId: input.petId, foodId: input.foodId, grams: input.grams, fedAt, ownerId: owner,
          costCents: input.grams * food.costCents / food.bagGrams,
        }).returning();
        await queueStockCheck(food.id, owner);
        return { feeding, grams: input.grams };
      },
    }),
    runsOutOn: action({
      access: "subscriber",
      input: { foodId: integer().notNull() },
      async handler(input, ctx) { return await projection(input.foodId, ownerId(ctx)); },
    }),
    costPerMonth: action({
      access: "subscriber",
      input: { petId: integer().notNull() },
      async handler(input, ctx) {
        const owner = ownerId(ctx);
        await ownPet(input.petId, owner);
        const now = Date.now();
        const meals = await db.query.feedings.findMany({ where: {
          petId: input.petId, ownerId: owner,
          fedAt: { gte: new Date(now - WINDOW_DAYS * DAY_MS).toISOString(), lte: new Date(now).toISOString() },
        } });
        const total = meals.reduce((sum, meal) => sum + meal.costCents, 0);
        return { petId: input.petId, costCents: Math.round(total / WINDOW_DAYS * 30) };
      },
    }),
    restockList: action({
      access: "subscriber",
      input: {},
      async handler(input, ctx) {
        const owner = ownerId(ctx);
        const foods = await db.query.foods.findMany({ where: { ownerId: owner } });
        const result = [];
        for (const food of foods) {
          const forecast = await projection(food.id, owner);
          if (forecast.needsRestock) result.push(forecast);
          await queueStockCheck(food.id, owner);
        }
        return result;
      },
    }),
  },
});
```
