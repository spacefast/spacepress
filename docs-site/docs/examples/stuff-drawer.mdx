## README

A personal inventory for cables, adapters, chargers, tools, books, and other small things, with a lending log. There is no custom frontend. WordPress owns the UI and sign-in.

This example currently **does not compile on main**. See [Known gaps](#known-gaps-on-main-b66e98b3). The published Space is a restricted source snapshot, not a working inventory app. Local HTTP verification, generated artifacts, and admin screenshots remain blocked by the compiler error.

## Data and screens

| Resource | Storage and UI | Fields |
| --- | --- | --- |
| Bins | WordPress collection, wp-admin and First Admin | name, location, photo, ownerId |
| Things | WordPress collection, wp-admin and First Admin | name, kind, connectorA, connectorB, lengthCm, wattage, binId, quantity, photo, tags JSON, ownerId |
| People | WordPress collection, wp-admin and First Admin | name, contact, ownerId |
| Loans | SQL table, First Admin lending log | thingId, personId, lentOn, dueOn, returnedOn, overdueAt, ownerId |

`admin: true` packages [First Admin](https://github.com/spacefast/zero/blob/main/docs/admin.md) at `/first-admin/`. Classic WordPress lists and edit screens use Secure Custom Fields. The loan table uses First Admin's table forms and relation pickers. Photo fields use WordPress media.

Each row belongs to the signed-in WordPress user. Read, update, and delete rules return an owner filter. `beforeCreate` stamps `ownerId` from that user; clients cannot supply or change it. Actions explicitly scope trusted database calls and validate that references belong to the same owner.

WordPress media URLs follow the site's media policy. Owning an inventory row does not make its photo bytes private on an otherwise public WordPress installation. The example Space restricts its whole site to the owning team.

## Actions and overdue stamps

| Action | Input | Result |
| --- | --- | --- |
| `find` | `query` | Matches every whitespace-separated query word against name, tags, and connectors, ignoring case. Returns each thing, its bin, whether any copy is lent, and the available quantity. |
| `lend` | `thingId`, `personId`, `dueOn`, optional `lentOn` | Creates a loan for one copy. Checks ownership, dates, and remaining quantity. Supports the `Idempotency-Key` header. |
| `giveBack` | `loanId`, optional `returnedOn` | Records the return. Repeating it preserves the first return date. |
| `overdue` | none | Open loans whose due date is before today, with the owned thing and person. |
| `whoHas` | `personId` | The person's current open loans, with the owned thing and person. |

Dates use UTC calendar days. `quantity` is the total owned, including lent copies. Available copies = `quantity - count(loans where thingId matches, ownerId matches, returnedOn is null)`.

The stock `job()` named `markOverdue` is queued after loan creation or update. Action Scheduler runs it after the end of `dueOn` in UTC. The job stamps `overdueAt` once and retains that timestamp as history after return. It checks the current owner, due date, and return state before writing, so an obsolete queued job cannot stamp a returned or extended loan. Jobs receive a trusted owner ID because their execution has no signed-in user. The job is not exposed as an agent ability.

`overdue` derives current lateness from dates even if Action Scheduler has not run yet. `overdueAt` records when the scheduler first observed lateness. No custom cron or worker loop is used.

### Native editor saves skip before hooks

[`types/zero/index.d.ts`](https://github.com/spacefast/zero/blob/main/types/zero/index.d.ts) documents the current contract verbatim:

\> On WordPress editor saves only the `after*` hooks run.

The owner assignments in `first.config.ts:111`, `:112`, and `:115` therefore do not run when a bin, person, or thing is created through wp-admin, SCF, or core REST. Those paths cannot currently establish the required ownership using this design. The bin ownership and quantity checks in `beforeUpdate` are also skipped by native editor saves. These are source-confirmed limitations, not successful live tests. Loans use table forms and the normal write pipeline.

### Lending capacity is not serialized

The app checks the number of active loans before inserting or editing a loan. Main exposes no row-lock operation through this database API. Concurrent requests on MySQL or MariaDB can both observe a remaining copy. The app does not claim atomic inventory reservation; concurrent lending has not been verified. An ordinary transaction alone does not make this check a reservation.

} from "first";
import { actorId, ownerId, personalAccess } from "./lib/ownership";

const bins = collection({
  name: text().notNull().min(1),
  location: text().notNull().min(1).ui({ help: "For example: hallway cupboard, top shelf." }),
  photo: media({ accept: "image" }),
  ownerId,
}, { title: "name", label: "Bins", access: personalAccess });

  name: text().notNull().min(1),
  kind: text({ enum: ["cable", "adapter", "charger", "tool", "book", "other"] }).notNull().default("other"),
  connectorA: text().ui({ label: "Connector A", placeholder: "USB-C" }),
  connectorB: text().ui({ label: "Connector B", placeholder: "Lightning" }),
  lengthCm: integer().min(0).ui({ label: "Length in cm" }),
  wattage: integer().min(0).ui({ label: "Power in watts" }),
  binId: integer().references(() => bins.id, { onDelete: "set null" }),
  quantity: integer().notNull().min(1).default(1).ui({ help: "Total owned, including copies lent out. Each loan is one copy." }),
  photo: media({ accept: "image" }),
  tags: json().$type<string[]>().notNull().$default(() => [])
    .validate((tags) => (Array.isArray(tags) && tags.every((tag) => typeof tag === "string")) || "Tags must be a JSON list of strings.")
    .ui({ help: 'A JSON list, for example ["travel", "iphone"].' }),
  ownerId,
}, { title: "name", label: "Things", access: personalAccess });

const people = collection({
  name: text().notNull().min(1),
  contact: text().ui({ help: "Email, phone number, or another way to reach them." }),
  ownerId,
}, { title: "name", label: "People", access: personalAccess });

  thingId: integer().notNull().references(() => things.id, { onDelete: "restrict" }),
  personId: integer().notNull().references(() => people.id, { onDelete: "restrict" }),
  lentOn: date().notNull().defaultNow(),
  dueOn: date().notNull(),
  returnedOn: date(),
  overdueAt: timestamp().access({ create: false, update: false })
    .ui({ help: "First overdue check by Action Scheduler. Kept after return as history." }),
  ownerId,
}, { label: "Lending log", access: personalAccess });

const collections = { bins, things, people };
const tables = { loans };
const relations = defineRelations({ ...collections, ...tables }, (r) => ({
  things: { bin: r.one.bins({ from: r.things.binId, to: r.bins.id }), loans: r.many.loans() },
  bins: { things: r.many.things() },
  people: { loans: r.many.loans() },
  loans: {
    thing: r.one.things({ from: r.loans.thingId, to: r.things.id }),
    person: r.one.people({ from: r.loans.personId, to: r.people.id }),
  },
}));

type Loan = InferSelectModel<typeof loans>;

async function checkBin(binId: number | null | undefined, owner: number) {
  if (binId == null) return;
  const bin = await db.query.bins.findFirst({ where: { id: binId, ownerId: owner } });
  if (!bin) throw new HttpError(404, "not_found", "Bin not found in your drawer.");
}

async function checkLoan(loan: {
  id?: number; ownerId: number; thingId: number; personId: number;
  lentOn: string; dueOn: string; returnedOn?: string | null;
}) {
  const thing = await db.query.things.findFirst({ where: { id: loan.thingId, ownerId: loan.ownerId } });
  const person = await db.query.people.findFirst({ where: { id: loan.personId, ownerId: loan.ownerId } });
  if (!thing || !person) throw new HttpError(404, "not_found", "Thing or person not found in your drawer.");
  if (loan.dueOn < loan.lentOn || (loan.returnedOn != null && loan.returnedOn < loan.lentOn)) {
    throw new HttpError(422, "invalid_input", "Due and return dates cannot precede the lending date.");
  }
  if (loan.returnedOn == null) {
    const active = await db.query.loans.findMany({ where: {
      ownerId: loan.ownerId, thingId: loan.thingId, returnedOn: { isNull: true },
    } });
    const otherLoans = active.filter((entry) => entry.id !== loan.id);
    if (otherLoans.length >= thing.quantity) throw new HttpError(409, "all_lent", "Every copy is already on loan.");
  }
}

async function scheduleOverdue(loan: Loan) {
  if (loan.returnedOn != null || loan.overdueAt != null) return;
  const deadline = new Date(`${loan.dueOn}T00:00:00.000Z`).getTime() + 86_400_000;
  await jobs.markOverdue.enqueue({ loanId: loan.id, ownerId: loan.ownerId }, {
    delay: Math.max(0, Math.ceil((deadline - Date.now()) / 1000)),
    key: `loan-${loan.id}-${loan.dueOn}`,
  });
}

async function describeLoans(owner: number, entries: Loan[]) {
  const result = [];
  for (const loan of entries) {
    const thing = await db.query.things.findFirst({ where: { id: loan.thingId, ownerId: owner } });
    const person = await db.query.people.findFirst({ where: { id: loan.personId, ownerId: owner } });
    result.push({ loan, thing, person });
  }
  return result;
}

  admin: true,

  hooks: {

        await checkBin(data.binId, actorId(ctx));
      },

      afterUpdate: scheduleOverdue,

          id: loanId, ownerId, dueOn: { lt: today },
          returnedOn: { isNull: true }, overdueAt: { isNull: true },
        });
      },
    }),
  },

        const words = query.toLowerCase().trim().split(/\s+/);
        const inventory = await db.query.things.findMany({ where: { ownerId: owner }, orderBy: { name: "asc" } });

        if (!person) throw new HttpError(404, "not_found", "Person not found in your drawer.");
        const entries = await db.query.loans.findMany({ where: { ownerId: owner, personId, returnedOn: { isNull: true } }, orderBy: { lentOn: "asc" } });
        return describeLoans(owner, entries);
      },
    }),
