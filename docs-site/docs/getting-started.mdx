Create a notes site on local WordPress. You will change its home page, display a new field on a note, and add an About page.

You need Node.js 22 or later and npm. TypedPress downloads WordPress and its local database for you.

## Create the site

Choose a directory name that does not exist yet.

```sh
npm create typedpress my-app
cd my-app
npm run dev
```

The first start downloads WordPress. When the terminal prints **Website**, open that URL. Click **Notes** to read the sample entries from `content/notes/`. Try the greeting form on the home page to see the result of a server action. **Account** takes you to WordPress sign-in and returns you to the page after you sign in.

:::note
The npm packages are not published yet. To run this guide from a [repository checkout](https://github.com/spacefast/zero), run `cargo build --release` there. Create the project with `node <repo>/packages/create-typedpress/bin/create-typedpress.mjs my-app --no-install`. From `my-app`, run `<repo>/target/release/typedpress dev`.
:::

## Edit the home page

Open `tp/app/page.tsx`. Change **Make this site yours.** inside the `<h1>` to **My walking journal**. Save the file. When the rebuild finishes, refresh the home page to see your heading.

All the pages share the header in `tp/app/layout.tsx` and the styles in `tp/app/site.css`. The layout reads the site name from a `global()` in `typedpress.config.ts`.

## Add a field to the notes

In `typedpress.config.ts`, add `location` to the fields passed to `collection()`, next to `summary`.

```ts
location: text().max(80).optional(),
```

Existing notes can keep this field empty. In `tp/app/notes/[slug]/page.tsx`, add this line below `<h1>{item.title}</h1>`.

```tsx
{item.location && <p>{item.location}</p>}
```

After the rebuild, open **Account** and sign in with the local login from the terminal. Follow **Open WordPress admin**, find **A first walk** under **Notes**, and enter **Riverside Park** in **Location**. Save the note and open `/notes/first-walk/` on your site to see the location below the title.

## Add an About page

Create `tp/app/about/page.tsx`.

```tsx
export const metadata = { title: "About" };

export default function About() {
	return (
		<>
			<h1>About this journal</h1>
			<p>A place to keep notes from walks around town.</p>
		</>
	);
}
```

Open `/about/` to see the page in the shared layout. To put it in the navigation, add `<Link href="/about">About</Link>` in the layout's `<nav>`. The page's URL comes from its folder under `tp/app/`.

## Stop the site

Press Ctrl+C in the terminal running `dev`, or run `npm run stop` in another terminal. Your notes and settings stay in the local WordPress database.
