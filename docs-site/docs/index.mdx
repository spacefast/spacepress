First (formerly Zero v2) is a framework for building app backends in TypeScript. You describe your data, your access rules and your server functions in one file, `first.config.ts`. `first build` compiles that file into WordPress plugins.

## What you get from one file

| You write | `first build` makes |
| --- | --- |
| A `collection()` | Posts in WordPress, with the editor, drafts and revisions |
| A `table()` | A MySQL table and a migration file |
| `access` rules | Checks that run on every read and write |
| An `action()` | A REST route at `POST /wp-json/first/v1/actions/<name>` |
| A hook or an action handler | PHP code. The compiler turns your TypeScript into PHP. |
| All of it | A typed JavaScript client in `first/client/` |

Rust runs only at build time. At runtime your app is plain PHP inside WordPress, with no Node.js server.

## Who it is for

Use First when an app needs a backend with users, content and an admin, and you want to write it in TypeScript. Your frontend can be anything that can call `fetch`. WordPress gives you the admin screens, the media library and the user accounts.

## Status

First is new. Its API will change before version 1.0. No npm package is published yet. Until one is, build the `first` command from the [repository](https://github.com/spacefast/zero).

If you have an app on Zero 0.8, read [Migrate from Zero 0.8](/migrating-from-zero).
