`first build` writes ordinary WordPress plugins to `first/dist/wp-content/plugins/`, each as a folder and a ZIP. The [WordPress plugins](/reference/wordpress-plugins) page lists the WordPress, PHP and plugin versions they need. [`/llms.txt`](/llms.txt) lists every page of these docs for an agent to read.
