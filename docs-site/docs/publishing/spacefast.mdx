:::

You publish your app's source, Spacefast compiles it on its own WordPress, and your app gets a `space.fast` address. You don't upload PHP or a database.

## Before you start

- You have a TypedPress app that passes `typedpress check`. The [getting started guide](/getting-started) makes one.
- You have a Spacefast account.

## Publish the app

1. Install the Spacefast CLI:

   ```sh
   npm install --global spacefast
   ```

2. Sign in:

   ```sh
   sf login
   ```

   The command prints a link. Open it and approve the sign-in.

3. Go to your app's directory. It is the one that holds `typedpress.config.ts`:

   ```sh
   cd my-app
   ```

4. Check the app:

   ```sh
   npm run check
   ```

   Fix every problem it reports before you continue.

5. Publish:

   ```sh
   sf publish
   ```

   The CLI compiles your source to a bundle on your machine, then uploads that bundle and the files in `public/`. The first publish creates a Space. The command prints its address, for example `https://my-app.space.fast`.

6. Open the address. Check that a page loads, then call one route:

   ```sh
   curl https://my-app.space.fast/wp-json/typedpress/v1/notes
   ```

To publish a new version, run `sf publish` again from the same directory. The CLI remembers the Space in `.spacefast/`.

## What runs on the Space

Each version runs the code it was compiled from. These work with no extra setup:

- The API under `/wp-json/typedpress/v1`, over WordPress's own REST routes. See the [API reference](/rest).
- Pages and HTTP handlers under `tp/app/` (`page.tsx`, `route.ts`), on their own paths, with the stylesheets and SVGs they import. See [Pages](/pages).
- `public/`, served as static files.
- The typed client at `/__tp/client.js`, with its types at `/__tp/client.d.ts`.
- Live updates. `watch()` in the client gets every committed change over Spacefast's realtime connection.

## Sign people in with Spacefast

A TypedPress app can sign people in with Spacefast like any other OAuth2 provider. Spacefast's login is standard OAuth2, so you register your app with Spacefast, get a client ID and secret, and add it as a sign-in provider of TypedPress Identity. The app needs no code that is specific to Spacefast.

## If publish fails

| Message | What to do |
| --- | --- |
| `tp_source_needs_local_capture` because an import needs npm packages | Run `npm install` in the app, then publish again from your machine. |
| The bundle has TSX pages from the old pages renderer | Move `pages/` to `tp/app/` ([Pages](/pages#from-the-old-pages-renderer)), then publish again. |
| A diagnostic code such as `F1002` | The compiler refused the config. Read the [diagnostic codes](/reference/diagnostics), fix the file and line it names, and publish again. |
