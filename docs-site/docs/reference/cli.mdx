The `typedpress` command comes from the `typedpress` npm package. Run `typedpress help <command>` to print one command's arguments.

## Build commands

These commands run on your machine, on the project's files.

| Command | What it does |
| --- | --- |
| `typedpress dev [dir] [--port n] [--url address \| --host address] [--no-watch \| --detach \| --foreground] [--allow-destructive]` | Start the local WordPress site and rebuild on change; --url is the address a proxy serves it at, --host an address of this machine to listen on. |
| `typedpress dev stop [dir]` | Stop the local site, keeping its data. |
| `typedpress dev status [dir] [--json]` | Report the local site. |
| `typedpress build [dir] [--out dir] [--quiet] [--preserve-data snapshot.json] [--frozen]` | Write the WordPress plugins to tp/dist/wp-content. |
| `typedpress export [dir] [--out dir] [--site url] [--base /path] [--site-url https://example.com]` | Write tp/app/ as a static site to tp/dist/static (output: "static"); --site renders a hosted site's content, signed in as an editor. |
| `typedpress check [dir] [--json] [--frozen]` | Compile and report problems; write nothing. |
| `typedpress add <module> [dir]` | Add a module to the project as files you own; never overwrites one. Modules: shop (WooCommerce storefront), db (SQL tables), api-reference (pages at /api documenting the HTTP API) |
| `typedpress doctor [dir] [--out dir] [--site url [--links]] [--json]` | Check a build, and a running site (signed in as an administrator to see what it loads); --links follows every link and #anchor its pages make. |
| `typedpress init [dir] [--check] [--github]` | Write AGENTS.md, .mcp.json and the agent skills for this project; --github adds the content sync workflow; --check exits 1 when they are out of date. |
| `typedpress mcp [dir] [--allow-remote-read] [--allow-writes]` | Serve the project to a coding agent as an MCP server on stdio. |
| `typedpress sync [status \| resolve <uid>] [dir] [--site url] [--only c1,c2] [--check] [--no-commit] [--pr [--repo owner/name] [--base branch]] [--json]` | Content files \<-\> site records. |
| `typedpress pull [dir] [--site url] [--check]` | Write a site's runtime schema versions to tp/_generated/runtime-schema.json, signed in as an administrator. |
| `typedpress styles pull [dir] [--site dir\|@alias] [--check]` | Write a site's Global Styles (the Styles screen, the Site Editor) over tp/theme.json; the build ships it and generates tp/_generated/theme.css. |
| `typedpress abilities pull [dir] --site url [--only vendor/*]` | Lock a site's abilities into tp/_generated/abilities.json. |
| `typedpress plugin [--out file.zip]` | Write the TypedPress WordPress plugin (typedpress.zip) to upload and activate in wp-admin. |
| `typedpress login <site-url> [dir] [--no-browser]` | Sign in to a WordPress site that runs the TypedPress plugin; the site's owner approves an application password in the browser, and every command that talks to the site uses it. |
| `typedpress logout <site-url>` | Forget a site's credential on this machine. |
| `typedpress push [dir] [--site url] [--dry-run]` | Compile the project and deploy it to the site: install the plugins it needs, upload the build, show what it changes, make it live. |
| `typedpress deploy <inspect\|publish\|init\|status\|backup\|restore> <options>` | Artifact preflight and offline workspaces ([docs/deployment.md](https://github.com/spacefast/zero/blob/main/docs/deployment.md)) |

## Site commands

These commands run inside WordPress. On a local site, run them as `typedpress <command>`. On a WordPress server, run them as `wp typedpress <command>`. Add `--site <dir | workspace | @alias>` to pick the site. Without it, the command uses the project's local dev site.

| Command | What it does |
| --- | --- |
| `wp typedpress migrate [--drop=<kind>=<rows>,...] [--mark-applied=<id>]` | Apply pending database migrations, checked against live rows. |
| `wp typedpress seed --records=<dir> [--dry-run]` | Typedpress-sync content from compiled records. |
| `wp typedpress jobs list [--state=s] \| run <id> \| retry <id> \| cancel <id> \| maintain \| tick [--limit=n] [--budget-ms=ms]` | Inspect and drive background jobs. |
| `wp typedpress abilities` | List the app's abilities. |
| `wp typedpress schema list \| diff <version> \| apply <file\|-> [--parent=<n>] \| rollback <version> [--parent=<n>]` | The site's runtime schema versions (runtimeSchema: true) |
| `wp typedpress run <ability> [--input=<json>]` | Run an ability. |
| `wp typedpress action <name> [json]` | Call an action as the trusted CLI. |
| `wp typedpress find <collection> [json options]` | Read records. |
| `wp typedpress insert <collection> <json>` | Insert records. |
| `wp typedpress update <collection> <where json> <set json>` | Update records. |
| `wp typedpress delete <collection> <where json>` | Delete records. |
| `wp typedpress git-dispatch status \| set [--repo=<owner/name>] [--token] \| clear [--token]` | The repository a save of synced content notifies; --token reads the token from stdin into WordPress's Secrets API. |
| `wp typedpress publish-due` | Publish scheduled records that are due. |
| `wp typedpress staged list [<kind>] \| show\|compare\|discard <kind> <id> \| stage <kind> <id> <json> \| promote <kind> <id> [--at=<ISO time> \| --cancel] (writes take --rev=<token>)` | Staged versions of post kinds: list, stage, compare, promote, discard. |
| `wp typedpress identity account\|suspend\|restore\|revoke\|erase <user-id> \| app add --name=n --redirect=uri --origin=o [--id=app_id] \| agent add <user> --name=n [--write] [--personal] [--abilities=a,b] \| agent list <user> \| agent grant <user> <id> [--write] [--personal] [--abilities=a,b] \| agent revoke <user> <id> \| webhook-add <url> \| webhook-remove <id> \| webhooks \| maintenance \| rotate-keys` | TypedPress Identity accounts, applications, agent credentials, webhooks and keys. |

`typedpress wp <WP-CLI arguments>` runs any WP-CLI command on the local site. For example, `typedpress wp plugin list`.

Site commands sign in with `TP_APP_PASSWORD` or `TP_TOKEN`.


## Create an app

`npm create typedpress <directory>` copies a starter app into a new directory and installs its dependencies. Add `-- --no-install` to skip the install. The directory must not exist yet.

The table on this page is read from [`runtime/TypedPress/Cli/commands.json`](https://github.com/spacefast/zero/blob/main/runtime/TypedPress/Cli/commands.json). The binary prints the same table for `typedpress --help`, and WordPress registers the same site commands.
