TypedPress runs on WordPress 7.2-beta5 or later and PHP 8.2 or later. The database is MySQL 8.0, MariaDB 10.11, or SQLite through the SQLite Database Integration plugin 3.1.2.

## Plugins TypedPress supports

`typedpress build` installs the plugins marked "Always installed" in every app. You don't list them in your config. Every plugin in this table is tested by the TypedPress team.

| Plugin | When | Pinned version | Supported versions |
| --- | --- | --- | --- |
| [`action-scheduler`](https://wordpress.org/plugins/action-scheduler/) | Always installed | `4.2.0` | 4.2.0 up to, not including, 5 |
| [`classic-editor`](https://wordpress.org/plugins/classic-editor/) | Allowed. Add it under `plugins` in your config | None | 1.6.7 up to, not including, 2 |
| [`mcp-adapter`](https://wordpress.org/plugins/mcp-adapter/) | Always installed | `0.7.1` | 0.7.1 up to, not including, 0.8 |
| [`polylang`](https://wordpress.org/plugins/polylang/) | Not installed while `locales` are turned off | `3.9` | 3.9 up to, not including, 4 |
| [`secure-custom-fields`](https://wordpress.org/plugins/secure-custom-fields/) | Always installed | `6.9.7` | 6.9.7 up to, not including, 7 |
| [`two-factor`](https://wordpress.org/plugins/two-factor/) | Always installed | `0.17.0` | 0.17.0 up to, not including, 0.18 |

The supported versions come from [`src/wp_plugins/supported.json`](https://github.com/spacefast/zero/blob/main/src/wp_plugins/supported.json). The pinned versions come from `plugins()` in [`src/platform.rs`](https://github.com/spacefast/zero/blob/main/src/platform.rs). The Rust and PHP test suites both compare those pins with [`tests/fixtures/platform.json`](https://github.com/spacefast/zero/blob/main/tests/fixtures/platform.json).

## Add another plugin

To add a plugin, name its WordPress.org slug and version under `plugins` in `typedpress.config.ts`. This is `examples/wp-plugins`:

<ExampleConfig name="wp-plugins" />

The typedpress build downloads the plugin and records its SHA-256 in `tp/wp-plugins.lock.json`. Commit that file. Later builds refuse an archive whose checksum differs.

A plugin that is not in the table above still installs. `typedpress check` and `typedpress build` print a warning for it. To ask for a plugin to be supported, [open an issue](https://github.com/spacefast/zero/issues) with its slug, the version you need, and what you use it for.
