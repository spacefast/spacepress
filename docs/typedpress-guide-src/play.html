Playground

Edit an app and it is compiled in your browser by the same compiler the command line uses. Then run your version in WordPress, also in your browser. Nothing is sent to a server.

These are the example apps as they are in the code today, so they use the current names: first.config.ts, first/, action(). The guide describes the names they are moving to.
