# Diagnostics observed during implementation

Baseline: `de46201a530e2bf1751abb54bf70cfda2a2caf2b`.
These are the diagnostic texts emitted while building and exercising this
example. The final source is rechecked on `ef0a42e3883eb146ad6318ff32cbc54cdb2e31d1`; the runtime and CLI
failures remain open.

This record was captured before the rename from First to SpacePress. The command
is written with today's name, `spacepress`, and so are the files the text names.

them: `first/` and `.first/` are `sp/` and `.sp/`, `first-diagnostics` is
`spacepress-diagnostics`, and `/wp-json/first/v1` is `/wp-json/spacepress/v1`.

## Runtime diagnostics still present

{"type":"about:blank","title":"Forbidden","status":403,"code":"forbidden","detail":"You can't set serialKey","pointer":"/serialKey"}

Triggered by `POST /wp-json/first/v1/drives` and by a drive edit that regenerates
the protected unique key. The trigger is `drives.serialKey` plus the owner read
filter in `spacepress.config.ts`.
