    TypeScript → PHP

    Give it a headline.

    This form calls a compiled action. A TypeScript class trims the title and generates a slug on the PHP backend. 

    Ready when you are.
    zero.config.ts · compiled at build time 
    class Headline {
  constructor(public text: string) {}
  preview() {
    const title = this.text.trim();
    return {
      title,
      slug: title.toLowerCase()
        .replace(/[^a-z0-9]+/g, "-")
        .replace(/^-|-$/g, ""),
      characters: title.length,
    };
  }
}

    A five-minute tour

    Go change something.

    1. Edit a story. Open “Read story & fields” on a story, then “Edit this story”. Sign in as admin. Change a title or paragraph, save, return here, and refresh.
    2. Try structured fields. Open the Fields panel: a group, repeater, layout blocks, JSON, and an image picker all come from the config. Change a link, quote, or JSON value, save, then refresh the open story to see it here.
    3. Follow the relation. Open Tasks in the admin. Change a task or its story, then refresh. The task’s status and related story update here too.
    4. Check the boundary. Public readers can read; edits and editor notes require an editor. The command below checks this with real HTTP requests.
    node examples/showcase/run.mjs check
