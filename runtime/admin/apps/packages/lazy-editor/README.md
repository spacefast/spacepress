# @typedpress-admin/lazy-editor

A lightweight package used by TypedPressAdmin to lazy-load editor settings and assets.

## Installation

> [!NOTE]
> Currently, this package is intended for use within an NPM workspaces context. You do not need to install it from the public NPM registry. Instead, import it directly as a workspace dependency in typedpress-admin and it will be consumed as a module in WordPress.
