# @zero-admin/load-assets

A lightweight package used by the load-editor script to inject scripts and styles into the document, in the correct order with inline scripts support.

## Installation

> [!NOTE]
> Currently, this package is intended for use within an NPM workspaces context. You do not need to install it from the public NPM registry. Instead, import it directly as a workspace dependency in zero-admin and it will be consumed as a module in WordPress.
